# 伙伴养成 UI 设计：晨昏种子型伙伴

## 目标

在“今日”页面建立一个低打扰、可长期陪伴的成长反馈环。用户完成一条有效记录后，伙伴状态发生可见但克制的变化，让记录行为拥有即时回响；伙伴不能反过来阻塞记录、制造连续打卡压力或假装理解用户情绪。

第一版只做今日页伙伴展示与状态切换，不扩展独立伙伴中心，不引入联网或模型调用。

## 已确认的产品决策

- 关系：同行型伙伴。
- 性格：安静观察者。
- 语气：克制诗性，固定内容库按规则选择。
- 个性化：只允许使用记录类型和标题，不读取或复述人名、公司、金额、项目等敏感细节。
- 语录：每日最多一次；普通日可有限换句；成长节点语录不可替换。
- 成长：按累计有效记录日计算，同一自然日最多成长一次。
- 有效记录：事件描述非空；保存失败不触发成长。
- 补写：旧日期可按正常一天计算，同一自然日不重复计算。
- 中断：不倒退；回来时温和重逢，不评价缺席。
- 成长节点：累计第 1、7、14、30 天。
- 第 30 天后：成熟不毕业，进入月度章节；每月收集一个小物件。
- 命名：完成首条记录后命名，1–8 个字符；改名需要明确确认。
- 重置：可在设置中单独重置伙伴，二次确认，不删除记录。

## 视觉阶段

当前四张独立完整素材按以下规则冻结：

| 累计有效记录日 | 视觉状态 | 语义 |
|---|---|---|
| 1 | 头顶小芽；底部保留根系藤蔓 | 初见观察，刚刚扎根 |
| 7 | 头顶花苞 | 开始舒展 |
| 14 | 头顶白花 | 熟悉节奏 |
| 30 | 头顶粉花，旁有蜜蜂 | 成熟不毕业，进入陪伴章节 |

四张图采用整图状态切换，不要求拆分身体、植物和蜜蜂图层。底部藤蔓是第 1 天的有意设计，不应被自动抹除或强行补到其他阶段。

## 今日页布局

伙伴位于今日页顶部主视觉区域，但输入框和“保存并沉淀”按钮必须继续保持首屏可见。推荐结构：

```text
┌──────────────────────────┐
│ 今日                     │
│                          │
│       [伙伴整图]          │
│   一起留下了 N 天          │
│   [当前阶段 / 语录]        │
│                          │
│   [记录输入框]             │
│   [保存并沉淀]             │
│                          │
│   今日记录列表             │
└──────────────────────────┘
```

伙伴区域不能使用大面积装饰背景、强渐变、玻璃拟态或游戏化徽章。素材本身承担视觉识别，外围布局保持留白和可读性。

点击伙伴展开轻量成长卡，展示：当前状态、天数文案、今日语录和下一成长节点。第一版不创建独立详情页。

## 动态行为

- 首次进入今日页：伙伴以当前阶段静态展示，昼夜只影响低频姿态或展示文案，不替换成长状态。
- 保存成功：先完成数据刷新，再播放短暂的舒展回应；若跨过第 1、7、14、30 天，显示一次“状态变化 + 语录”节点提示。
- 同一天第二次保存：不重复增加成长，不重复播放成长节点；普通保存可以保留轻微回应。
- 保存失败：进入等待重试状态，不播放成长、不改变天数。
- 普通阶段切换：使用短时淡入淡出和轻微缩放，禁止快速跳帧或夸张弹跳。
- 用户减少动画：状态仍需完整可见，动画直接跳到最终状态。

## 前端实现边界

- 伙伴状态是 AppState 可持久化的应用数据，不在 Widget 内部自造第二份真相。
- 成长计算必须以有效记录和自然日去重为依据。
- 记录保存、伙伴成长、状态刷新应保持同一操作边界，不能先播放动画再假设保存成功。
- 语录选择必须是本地、可测试、可复现的规则，不调用 LLM。
- 整图素材统一在展示容器中处理尺寸和底部基线，不要求生图素材完全同尺寸。
- 首版不实现素材分层编辑、独立伙伴中心、月度章节完整内容或联网同步。

## 验收标准

1. 第 1、7、14、30 个累计有效记录日显示正确伙伴图。
2. 同一自然日多次记录不会重复增加成长。
3. 失败保存不会改变伙伴状态。
4. 删除记录不会回退历史成长。
5. 漏记后回来不会扣除成长，并能显示温和重逢状态。
6. 保存成功后的伙伴回应不会把输入框或保存按钮推出首屏。
7. 点击伙伴可展开成长卡，关闭后今日记录流程不丢失。
8. 四阶段切换在亮色和深色主题下都保持清晰可辨。
9. 四阶段素材保持同一伙伴身份；第 1 天底部藤蔓保留。
10. `flutter analyze` 无问题，现有测试全绿，并通过雷电本地 Android MCP 完成今日页实机验证。
