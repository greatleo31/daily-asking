# 保存高价值任务记忆

## 保存范围

只保存会让未来任务更快或更安全的内容：

- 约束后续实现的产品或架构决策。
- 可复用的文件、符号和接口入口。
- 已纠正且可能复发的错误与预防规则。
- 会影响下一次任务的未决事项。

产品行为、架构规则、API、数据、安全和发布契约应进入 OpenSpec 主规格或 ADR；Topic MEMORY 只保存索引和应用提示。

## 更新规则

- 增量更新 `topics/<topic>/MEMORY.md`，保留已有有效内容。
- 里程碑需要追溯时才新增 `sessions/YYYY-MM-DD-HHMM-<描述>.md`，保存摘要而非聊天转录。
- 删除、大范围重写、跨 Topic 移动或把模糊结论升格为长期规格前必须取得用户确认。
- 不保存凭据、密钥、个人敏感信息和没有结论的草稿。

## 输出

报告已保存、已跳过、更新文件、需要确认和下一次应打开的上下文。没有值得保存的内容时明确说明，不制造记忆。
