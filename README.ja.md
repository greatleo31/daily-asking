# Daily Asking（晨昏証拠図譜）

> ローカルファーストの職場エビデンス成長アシスタント：毎日一つの「本当にあった小さな出来事」を記録し、痕跡をエビデンスに、エビデンスを成果に変える。

[中文](README.md) · [English](README.en.md) · [MIT License](LICENSE)

Daily Asking は**ローカルファースト**のモバイルアプリです。「今日あった本当の小さな出来事」を起点に、構造化されたフォローアップ質問を通じて、散らばった仕事メモを検索・再利用可能な**職場エビデンスグラフ**へと変え、必要なときに履歴書の要点・週報・面接質問カードをワンタップで生成します。

**核となる考え方：データはあなたのもの。AI はオプション。**

---

## ✨ 特徴

- **ローカルファースト、プライバシー標準装備**：すべての記録は端末内に保存。アカウント不要、ログイン不要、サブスクリプションなし、クラウド同期なし、テレメトリなし。
- **毎日一問**：記録を保存すると、ローカルルールエンジンが「最も補足する価値のある」質問を最大一つ（結果 / 背景 / 行動 / 課題 / 個人貢献）投げかけ、走り書きを完全なエビデンスに育てます。
- **エビデンスグラフ**：時間とタグで全記録を閲覧。全文検索と直近 7 日 / 30 日の絞り込みに対応し、充足度もひと目で分かります。
- **スタジオ（任意の AI）**：1 件以上のエビデンスを選んで、履歴書の要点 / 週報 / 面接質問カードを生成。
- **BYOK（Bring Your Own Key）**：AI 呼び出しにはご自身の API キー（OpenAI 互換）を使用。キーは端末内の隔離ストレージにのみ保存され、画面には表示されません。実際の呼び出しの前には**送信内容の開示**を行い、確認後に選択した最小限のフィールドだけを送信します。
- **テーマ切替**：システム / ライト / ダーク。
- **バージョン更新**：アプリ情報ページで手動チェック、起動時に自動チェック。「自動更新」を有効化でき、強制更新はスキップできません。更新マニフェストと APK の検証は [docs/02-版本与更新机制.md](docs/02-版本与更新机制.md) を参照してください。

## 🧭 画面の紹介

| ページ | 説明 |
| --- | --- |
| 今日 | 本当にあった小さな出来事を素早く記録し、ローカルの質問に回答 |
| エビデンス | すべてのエビデンス記録を検索・絞り込み、充足度を確認 |
| スタジオ | エビデンスを選んで履歴書 / 週報 / 面接カードを生成 |
| 設定 | テーマ、任意の AI（BYOK）設定、プライバシー説明 |

## 🏗️ アーキテクチャ

- `lib/core/` — ドメインモデル、ストレージ抽象、任意の LLM クライアント
- `lib/evidence/` — エビデンス記録、フォローアップエンジン、エビデンスグラフ
- `lib/journal/` — 今日ページ
- `lib/artifacts/` — スタジオと成果物の管理
- `lib/settings/` — 設定、BYOK 設定と API キーの暗号化ストレージ
- `lib/updater/` — バージョン確認と更新メカニズム
- `lib/app/` — アプリシェルとグローバル状態

詳細は [docs/architecture.md](docs/architecture.md) を参照してください。

## 🔒 セキュリティ

- ログに API キー、記録本文、プロンプト全文は記録しません。
- 実際の AI 呼び出しでは、送信確認後に選択した最小限のフィールドのみを送信します。
- セキュリティ問題の報告は [SECURITY.md](SECURITY.md) をご覧ください。
